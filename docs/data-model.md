# Модель данных и методология Niche Radar

## Сущности (ТЗ §8)

| Таблица | Назначение |
|---|---|
| `source_files` | Оригиналы CSV: SHA-256 (unique), размер, путь. Одинаковый файл не дублируется |
| `datasets` | Ревизия обработки файла: mapping JSON, политика, coverage_type, статус, quality flags |
| `dataset_scans` | Замеры: `ordinal` 1=самый старый; исходный суффикс колонки; nullable `scan_date` |
| `keywords` | Глобальный словарь фраз: `phrase_original`, `identity_hash` (NFC+trim), `search_text`, кеш признаков задачи |
| `dataset_keywords` | Принадлежность фразы отчёту: ранги, исходные длины, unique(dataset_id, keyword_id) |
| `observations` | (scan_id, keyword_id) → exact/broad bigint NULLable; значения ≥ 0 |
| `keyword_tokens` | Токены (Unicode-буквы/цифры) для токенного поиска и групп |
| `metric_runs` | Прогон: диапазон замеров, версия алгоритма, профиль, хеш параметров (переиспользование) |
| `keyword_metrics` | Метрики прогона: B/R/A/G/C/P, T, priority, флаги, `null_reasons` |
| `niche_versions` / `niche_members` | Неизменяемые версии состава ниши с агрегатами |
| `hypotheses` / `hypothesis_evidence` | Гипотезы; доказательства фиксируют значения на момент записи |
| `saved_searches`, `brand_dictionaries`, `rule_sets`, `keyword_labels`, `keyword_notes` | Пользовательские словари и настройки |
| `import_jobs` / `import_errors`, `export_jobs`, `analytics_jobs` | Фоновые задания с прогрессом/heartbeat и общий механизм jobs |

Ключевые индексы: `observations(keyword_id, scan_id)`, `keyword_metrics(metric_run_id,
priority DESC NULLS LAST, keyword_id)` (+ exact/A/G), `keywords` GIN `pg_trgm` по
`search_text`, `keyword_tokens(token)`.

## Обработка пропусков и состояния

- Пустая ячейка CSV → `NULL` (пропуск); `0` → наблюдаемый ноль; отсутствие строки —
  фразы нет в отчёте. Эти три состояния различаются во всех интерфейсах.
- `rank_previous = 0` — «не было в прошлом рейтинге»; фиктивный rank_delta не создаётся.
- Сглаженные метрики (B/R/A/G/C/P) считаются только для полного ряда ≥ 4 замеров;
  иначе NULL с причиной (`insufficient_history` / `incomplete_series`).
- Процент роста при `f1 = 0` не определён (`zero_baseline`); показывается «рост от нуля»
  и абсолютное изменение. Скрытая прибавка единицы к знаменателю не используется.
- `P = fn / max(ряд)`; при нулевом максимуме — NULL (`zero_peak`).

## Формулы (metrics_v1)

Для точных частотностей `f1..fn` от старого к новому:

```
B = (f1 + f2)/2           ранняя база
R = (f[n−1] + fn)/2       поздний уровень
A = R − B                 сглаженный прирост
G = (R − B)/B   при B>0   сглаженный рост
C = #{f[i]>f[i−1]}/(n−1)  устойчивость (равные значения не считаются ростом)
P = fn / max(f1..fn)      сохранение относительно наблюдаемого пика
```

Граничное сравнение `fn − f1` и `(fn−f1)/f1` (при `f1>0`) доступно и без полного ряда.

Приоритет `priority_v1` (полная история, `B ≥ 20`):

```
g = clip(G/2); a = clip(ln(1+max(A,0))/ln(10001)); v = clip(ln(1+fn)/ln(100001))
priority = round(100 × (0.30g + 0.25a + 0.20C + 0.15v + 0.10T))
```

`T` — максимум веса сработавших правил признаков задачи (0…1; словарь версионируется).
Значения приоритета при низкой базе/пропусках — NULL с причиной. Масштабы (2, 10000,
100000) и веса — стартовый профиль; при изменении создаётся новая версия профиля и
пересчёт, прежние результаты сохраняются.

Пресеты: «Устойчивый рост» (n≥4, fn≥100, B≥20, A≥50, G≥0.30, C≥0.60, P≥0.70),
«Ранние сигналы» (0<B<20, fn≥50, A≥30, G≥1, C≥0.60, P≥0.70 — пониженная надёжность),
«Рост от нуля» (B=0, fn≥50, A≥30, P≥0.70), «Лидеры роста»/«Лидеры падения»
(полный ряд без порогов, сортировка по A убыв./возр. — как одноимённые карточки
дашборда). Пресеты не смешиваются.

## Ничши (§7.5)

- Состав: `(совпадение с фильтрами ИЛИ ручное включение) И НЕ ручное исключение`;
  фиксированная ниша — только ручные списки.
- Динамика считается по `K_complete` (полный ряд всех выбранных замеров); исключённые
  из-за неполной истории фразы перечисляются, нулями не заменяются.
- Агрегаты: суммы по замерам, доля растущих, доля лидера, медиана G (по участникам с
  положительной базой), лидеры вклада в A. Скалярного приоритета ниши нет — сравнение
  по нескольким показателям.
- Пересчёт всегда создаёт новую версию; прежние версии воспроизводимы.

## Сравнение отчётов (§7.5)

Только текущие замеры; только при совпадении региона и определения частотности
(иначе `INCOMPATIBLE_MEASUREMENTS`). Рост суммы — на пересечении фраз; вошедшие и
отсутствующие фразы — отдельные списки; отсутствие не превращается в ноль.

## Ограничения источника

- Даты замеров неизвестны: ось порядковая, календарные/месячные темпы не рассчитываются.
- История внутри отчёта описывает только фразы текущего топа, не весь рынок.
- Ранги 2…11 или фрагменты допустимы; ранги не перенумеровываются; охват задаётся
  вручную (`coverage_type`) и не выводится из имени файла.
- Идентичность фраз: NFC + trim; `ё/е`, лемматизация — только как явный режим поиска.
